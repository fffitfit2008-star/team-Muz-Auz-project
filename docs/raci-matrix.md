# Матрица RACI для проекта «Муз-Арбуз»

| Задача проекта | Руководитель (Капитан) | Архитектор | Тестировщик |
| :--- | :---: | :---: | :---: |
| Выбор темы и создание репозитория | **A** | **R** | **I** |
| Разработка правил взаимодействия | **A** | **R** | **R** |
| Написание отчетов по работам | **A** | **R** | **R** |
| Проверка Pull Request и Merge | **A / R** | **C** | **I** |

*Обозначения:* **R** — Исполнитель, **A** — Ответственный, **C** — Консультант, **I** — Информируемый.
